Garantir Stock Exchange
Overview
Garantir Stock Exchange is a real-time financial analytics platform designed to provide users with dynamic stock market insights, portfolio tracking, and secure transaction management. Built using React, Vite, and the Alpha Vantage API, it ensures efficient financial data retrieval and analysis.
Features
- Real-time Stock Data – Fetches live market trends and stock performance using the Alpha Vantage API.
- Optimized Database – Implements a PostgreSQL schema for financial data warehousing, ensuring fast retrieval and analytics.
- Secure Authentication – Uses JWT authentication and rate limiting to enhance security and prevent unauthorized access.
- Performance Optimization – Integrates Redis caching and indexing to reduce API response time and improve efficiency.
- User Portfolio Management – Allows users to track transactions, monitor stock 
- performance, and analyze historical data.
Tech Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: FastAPI, PostgreSQL, Redis
- API Integration: Alpha Vantage API
- Security: JWT Authentication, Rate Limiting
